Description

Music Portfolio Website is a web development project I created to showcase my musical works and audio production skills. The website serves as a digital portfolio for my music career, featuring audio samples, latest releases, and professional information for potential collaborators and clients.


The website includes features such as audio streaming through soundcloud's embed player, project showcases with descriptions of my work, and contact forms for booking inquiries. The website also provides information about my background in music production.


Key Features

The website includes responsive design to ensure optimal viewing on various devices, a language switcher for english and finnish, SEO optimization to enhance online visibility, and work-in-progress social media integration. The website is built using React for the front-end, with AWS services for hosting and backend functionalities. The AWS infrastructure uses AWS CDK for easy deployment and management, ensuring scalability and reliability. It's hosted through AWS S3 with a CloudFront distribution for fast content delivery, and AWS Route 53 for domain management.


Development Status

Currently this project is in active development. I am implementing additional features such as built-in music player so I don't have to rely on external services, social media integration, and content management capabilities. Implementation of AWS Dynamo DB as database is planned for future development. The site will continue to evolve as my music portfolio grows.
